# Chamada

Repositório com dois projetos:

- **[`igreja-aberta/`](igreja-aberta/README.md)** — app (PWA) da escala do grupo
  "Igreja Aberta": os irmãos se cadastram, marcam os dias em que não podem, o
  administrador gera a escala do mês com um toque, o texto sai pronto para o
  grupo do WhatsApp e cada um recebe um lembrete no celular no seu dia.
  👉 [Instruções de uso e instalação](igreja-aberta/README.md)

- **`chamada.py`** — programinha em Python/Tkinter para registrar presença em
  um banco SQLite local (`chamada.db`).
